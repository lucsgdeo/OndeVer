# Ideia do Projeto

- Fazer um tracking de onde assistir os Jogos da NBA.
- Deve ser claro e ter uma interface limpa

# Layout da página

- Os jogos devem aparecer em lista
- Deve ter o nome do time, a logo, o horário e onde vai passar no Brasil
- A layout deve ser parecido com o Sofascore, porém um pouco mais próximo de uma planilha
- Deve possuir uma pesquisa por time
- Deve possuir filtros de plataforma
- Deve priorizar o dia e horário atual

# Aspectos técnicos

- Deixo a seu cargo de onde tirar os dados dos jogos, mas deve ser salvo em um json dentro do projeto
- Deve ser usado Typescript e React para fazer o projeto
- Deve seguir o Clean Code e Clean Arch para melhor organização
- Deve ter um readme com os dados do projeto
- Deve estar adqueado apara o github pages
- Deve ter um layout responsivo, para acesso em desktops e dispositivos móveis
